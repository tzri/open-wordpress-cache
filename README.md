# Open WordPress Cache

*"The fast, lean, no‑BS page cache for WordPress."*

**Open WordPress Cache** is a **free** and **open-source** page caching plugin for [WordPress](https://wordpress.org/). It saves copies of your public pages as HTML, and serves them through PHP, reducing the server load needed to build the same page over and over again for every visitor.

## Usage

Enable caching on your site by following these steps:

1. Download [the latest zip archive](https://github.com/tzri/open-wordpress-cache/archive/refs/heads/main.zip) for an installable plugin ZIP.
2. Install the plugin.
3. You're done – Enjoy the benefits caching. 😎

## Details

The _Open WP Cache plugin_ focuses on practical page caching, with single settings screen and no complicated setup.

The plugin is designed to be **automatic** and **foolproof** on every aspect:
 * Super-easy to install
 * Zero-configuration
 * Ultra compatible
 * Conflict-aware

Minimal settings are available but the plugin works straight out-of-box *with no configuring required*. There are no ads, upsells, telemetry, remote assets or production dependencies. 

If cache storage cannot be used, WordPress serves pages normally.

## Features List

| FEATURE | DESCRIPTION |
| :------------ |:--------------|
| **Page Caching**  | Stores public pages locally on your server and reuses them for anonymous visitors. |
| **Automatic Clearing** | Refreshes the cache when you change content, comments, menus, widgets, themes, or site settings. |
| **Clear Cache Button** | Clears the server cache whenever you need a fresh start. |
| **Simple Settings** | Choose how long cached pages last and exclude specific URL paths. | 
| **Privacy Safeguards** | Skips logged-in visitors, requests with cookies or query strings, and common private or dynamic pages. | 
| **WooCommerce Support** | Skips cart, checkout, and account pages, including customized WooCommerce page URLs. |
| **Optional GZip** | Compresses eligible cached HTML when your server supports it. |
| **Browser Caching Controls** | Supports browser revalidation and an optional browser cache lifetime for HTML. |
| **Cache Status and Estimates** | Shows storage use and estimated cache activity without collecting visitor details or sending telemetry. |

## Installation

### Super-Easy Setup (compared to other WordPress caching plugins)

The focused design of Open WP Cache keeps the settings simple and helps limit the extra work the plugin adds to your site. No configuration circus required.

**Only pre-requisite**: You need a writable local WordPress uploads directory (`wp-content/uploads/`) which you most likely have.

### Install Steps
1. Download the [plugin ZIP](https://github.com/tzri/open-wordpress-cache/archive/refs/heads/main.zip).
2. In WordPress, go to **Plugins → Add New Plugin → Upload Plugin**.
3. Choose the ZIP, install it, and activate the plugin.
4. (Optional) Go **Settings → Open WordPress Cache** to review the settings.
5. You're done!

No need to change `wp-config.php`, server settings, directory permissions, or manage `.htaccess` files on the server. Caching starts automatically after activation – and it just works! 👌
